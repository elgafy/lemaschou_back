## About PixelCrafters Laravel Bootstrap

PixelCrafters Bootstrap is a Bootstrap for laravel.
It is a bootstrap for laravel that is easy to use and easy to customize.
It is also a good starting point for a new laravel project.


## Prerequisites
The following are the minimum requirements to run this project:
- PHP 8.2+
- Laravel 13.x
- Composer 2

## Installed Packages
- Laravel Framework 13.x
- l5-swagger 8.x

## Development Packages
- Laravel Telescope 5.x
- FilamentPHP 3.x
- Laravel Debug bar 3.x
- Laravel IDE Helper 3.x

## Contributing to PixelCrafters Laravel Bootstrap
Contributions are welcome and appreciated. Please follow the guidelines below:
    
1. Fork the repository and create your branch from `main`.
2. Make your changes and commit them with descriptive commit messages.
3. Push your branch to your forked repository.
4. Create a pull request from your branch to the `main` branch of the original repository.

## Usage for other projects
If you want to use this project for other projects, you can use the following steps:
1. Clone the repository.
2. Rename the project name in .env file.
3. Fill in the database information in .env file.
4. Run the following commands:
```
composer install
```
5. You can access the project at http://localhost:8000
6. You can access the swagger at http://localhost:8000/api/docs
